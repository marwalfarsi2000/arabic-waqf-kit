# Development roadmap (proposed, not yet shipped)

- v0.1: Conservative sentence-ending cleanup, CLI, unit tests, safe output handling — implemented in the draft.
- v0.2: Gather opt-in community examples, document ambiguous punctuation/quote behavior, improve edge-case tests.
- v0.3: Optional word-level annotation mode showing changes for human review; no automatic external uploads.
- v0.4: Integrate as an optional, reversible stage in public Arabic TTS workflows and collect quality feedback.

## Outcomes to measure (not current achievements)

- Independent users who reproduce the CLI successfully.
- Correctly handled regression cases with published expected behavior.
- External contributors and merged external pull requests.
- Zero unreviewed breaking changes to diacritic behavior.

No claims are made about stars, downloads, other users, public adoption, or grant eligibility.
