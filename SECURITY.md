# Security policy

Arabic Waqf Kit v0.1.0 is an experimental offline text-processing library.

- Do **not** include credentials, personal data, or private source texts in public issues and pull requests.
- For security vulnerabilities, please use GitHub's private vulnerability reporting feature if it is enabled for this repository.
- If private reporting is unavailable, do not disclose exploitable details publicly; request a private contact path via a non-sensitive issue.
- The project does not make network requests or send text to external services.
